# ReachDog — Privacy & Support

Hosts the public **Privacy Policy** and **Support** pages for the [ReachDog](https://github.com/biceps1/ReachDog) iOS app, for Apple App Store submission.

## Live URLs

- Home: https://biceps1.github.io/ReachDogPrivacy-Support/
- Privacy Policy: https://biceps1.github.io/ReachDogPrivacy-Support/privacy.html
- Support: https://biceps1.github.io/ReachDogPrivacy-Support/support.html

## How to publish

1. Push this repo to GitHub (already done if you're reading this).
2. On GitHub: **Settings → Pages** → Source = **Deploy from a branch** → Branch = **main** → Folder = **/ (root)** → Save.
3. Wait 1–2 minutes for the first build.
4. Visit the Live URLs above.

## Files

- `index.md` — landing page linking to both
- `privacy.md` — Privacy Policy (App Store compliant)
- `support.md` — Support / FAQ / Troubleshooting
- `_config.yml` — Jekyll config with minimal theme
